# 전체 페이지 UI/UX 개선 기록

## 범위

사용자 확인에 따라 메인을 제외한 기존 전체 페이지를 개선했습니다. 기존 구현은 6개 퀘스트이며, 여자친구 GPT는 구현되어 있지 않습니다. 새 페이지, 일곱 번째 완료 조건 또는 라우트를 추가하지 않았습니다.

메인, 모든 픽셀 캐릭터 컴포넌트, 기존 데이터와 라우팅, 진행 상태 저장 모듈은 작업 전후 SHA-256이 동일함을 확인했습니다. 기존 README 수정 사항도 건드리지 않았습니다.

## 디자인 변경

| 화면 | 변경 |
| --- | --- |
| 허브 | 반복되는 큰 카드를 열린 2열 목록으로 전환. 모바일은 1열. 플레이어·경험치·최종 보상의 위계 정리. 캐릭터 크기와 렌더링 규칙 유지. |
| 데이트 | 추상적인 탐험 경로와 장소 목록, 추억 상세를 분리. 실제 좌표를 임의로 만들지 않고 기존 Naver 지도 링크 유지. |
| 궁합 | 두 플레이어 입력 정보와 결과를 구분. 점수와 10개 분석 문장을 나란히 배치하고 모바일에서는 세로 재구성. |
| 벤치마크 | 실행 헤더, 행 단위 평가 지표, 최종 연구 결론을 구분. 기존 5개 만점 지표와 롤 실력 측정 보류 유지. |
| 가챠 | 추첨기와 쿠폰을 구분. 당첨 결과에만 240ms 등장 효과, 모션 감소 환경에서는 생략. 저장·재추첨·확률 유지. |
| 퀴즈 | 제출 수에 따른 진행 표시, 넓은 선택 행, 선택 상태, 정오답 결과 표시. 6문항 제출 조건과 재시도 유지. |
| 연애 GitHub | 7행·53열 연간 기여도 그래프와 월/요일/5단계 범례, 연결된 활동 타임라인. 각 커밋의 기존 제목·날짜·설명 및 클릭 완료 조건 유지. |
| 엔딩 | 편지의 외곽 박스를 줄이고 문단 간격과 한글 행간을 개선. 기존 편지·캐릭터·6개 완료 해금 조건 유지. |

공통 규칙은 `src/page-refinements.css`에 한정했습니다. 다른 화면에 영향을 주는 루트 색상·전역 타이포그래피 변경 없이, 페이지 단위 클래스를 사용합니다.

## 수정 및 추가 파일

- `src/main.tsx`: 페이지 전용 정돈 스타일 로드.
- `src/components/QuestShell.tsx`: 페이지별 스타일 클래스와 완료 상태 클래스.
- `src/page-refinements.css`: 공통 규칙, 허브, 상세 페이지, 엔딩, 반응형 및 모션 감소.
- `src/features/DatesQuest.tsx`: 탐색/추억 상세 구성.
- `src/features/FakerQuest.tsx`: 분석 결과의 시각적 그룹 구분.
- `src/features/ReportQuest.tsx`: 지표/결론 구성.
- `src/features/GachaQuest.tsx`: 추첨기/당첨 결과 구성.
- `src/features/QuizQuest.tsx`: 진행 표시/결과 피드백.
- `src/features/GithubQuest.tsx`: 기존 커밋을 활용한 활동 타임라인.
- `src/features/github-quest.css`: GitHub 전용 스타일.
- `src/components/LoveContributions.tsx`: 기여도 그래프와 날짜 탐색.
- `src/data/love-contributions.mjs`, `src/data/love-contributions.d.mts`: 편집 가능한 예시 잔디 데이터 및 UTC 달력 구성.
- `tests/contributions.test.mjs`, `package.json`: 기여도 데이터 테스트와 기존 테스트를 함께 실행.

## 기여도 데이터와 접근성

`love-contributions.mjs`의 `contributionArtwork`에서 연도, 하트 패턴, 시작 열, 문구를 수정할 수 있습니다. 현재 2026년의 고정 예시 활동 수이며, 실제 개인 일별 활동 기록으로 제시하지 않습니다. 화면에 예시 표시와 기존 장식 안내 문구를 유지합니다. 등록된 연애 날짜를 바꾸거나 `11.01`의 연도를 임의로 결정하지 않습니다.

합계는 모든 표시 날짜의 활동 수를 더해 계산합니다. 한 개의 Tab 진입점과 방향키, Home/End, Ctrl+Home/End로 날짜를 탐색하며, 클릭·터치·포커스·마우스 진입 시 정보가 표시됩니다. 모바일에서는 그래프 영역 안에서만 가로 스크롤합니다.

## 검증

- TypeScript 및 Vite 프로덕션 빌드 성공.
- `npm test`: 기존 진행 상태 4개 + 기여도 달력 3개, 총 7개 통과.
- 설치된 Edge의 별도 테스트 프로필에서 실제 React UI 이벤트로 25개 항목 확인. 테스트 페이지와 프로필은 `.tools/ui-review/`에만 존재하며 배포에 포함되지 않습니다.
- 확인한 기능: 3개 장소 열람, EXP 최초 1회 지급, 궁합 10문장, 벤치마크 6지표, 쿠폰 저장·화면 재진입 복원, 선택 전 퀴즈 제출 차단, 6문항 완료·결과 설명, 커밋 상세, 마지막 release만 완료, 앱 재마운트 후 진행 복원, 6개 완료 엔딩 해금, 초기화 취소/확인.
- 기여도: 365일, 총합 일치, 단일 Tab 진입점, 우측 방향키로 7일 이동, 클릭 시 날짜 정보 갱신.
- 1280px PC, 768px 태블릿, 390px 모바일의 대표 화면을 캡처. 320px GitHub 추가 검사. 확인한 모든 프레임에서 페이지 전체 가로 넘침 없음.
- 모바일은 실제 기기 대신 고정 너비 테스트 프레임으로 CSS 레이아웃을 검증했습니다. 물리 기기의 터치·가상 키보드·스크린리더 조작은 별도 확인이 필요합니다.

캡처와 테스트 출력: `.tools/ui-review/`. 대표 비교 이미지: `.tools/ui-review/github-review.png`.
